# 星核猎手的剧本

让卡芙卡写下这次行动的剧本，再发出召集令。刃、银狼和流萤各自在自己的会话里接令，共同写完这个故事。

## 开场前

1. 在同一个 DSH 工作区锻造四个会话，分别命名为 **卡芙卡、刃、银狼、流萤**。为每人选好角色 Persona，给四人配上可读写工作区文件的工具，并各发送一条消息，让会话进入召集令名册。
2. 锻造卡芙卡时开启**领袖模块**。另外三人只需能接令。想体验召回，可以在银狼回复第一句话后，先把她归档。
3. 想让剧本出现在**议事厅**，就在锻造四人时都开启议事厅。文档偏好可以给卡芙卡选 **Runbook**，给三位队员选 **Work Report**。剧本的格式见下方可追加的提示词。

## 发给卡芙卡

```text
卡芙卡，帮我做一件事。在工作区写一份星核猎手本次任务的剧本。去哪儿、要拿到什么、哪一步会出意外，都由你来想。给自己写一场开场戏，再给刃、银狼和流萤各留一场只有本人才能写完的戏。给他们同一条线索，让它在三个人手里都有不同的意义。

先把剧本保存为 Markdown 文件，再查本工作区的召集令名册，逐一点名通知刃、银狼和流萤。如果有人已经归档，我授权你恢复这次任务里被点名的队员。恢复后重新查名册，再把任务发给本人。

每条召集令都带上剧本的相对路径，告诉对方从哪一幕接手、需要作出什么选择，以及把写好的场景存在哪个文件。让三个人各写各的文件。等你发完，告诉我从哪里读开场、谁收到了召集令、谁是从归档中回来的。如果有人没联系上，也告诉我名字。
```

## 和议事厅联动（可选）

如果四人都已开启议事厅，把下面这段追加到同一条消息末尾，再一起发给卡芙卡。

```text
这次在议事厅留档。请把主剧本写成一份 Runbook，存在工作区的 .session-forging/council/星核猎手/主剧本.md。开头写你的开场戏，接着按「行动目标、各幕负责人、入场信号、意外发生时的选择、收场条件」编排行动。让每条召集令都指向这份剧本。

请刃、银狼和流萤把各自的一幕写成第一人称行动记录，作为 Work Report 放进主剧本所在目录，分别叫作 刃.md、银狼.md、流萤.md。每人写出自己看到了什么、做了哪个选择，以及那条线索最后落到了谁手里。
```

在卡芙卡的「锻造 → 召集令」里可以核对每条消息的投递结果。要看某位队员是否已经演完那一幕，可以打开他的会话，或直接读召集令里约定的场景文件。启用议事厅时，四份文档也会出现在「锻造 → 议事厅」里。
